# apolenkov.github.io

Personal page of Alexander Polenkov: a password-protected profile deck.
Site: <https://apolenkov.github.io>.

This repository holds only the published build. `index.html` is a
[StatiCrypt](https://github.com/robinmoisson/staticrypt) ciphertext; without the password a visitor
sees the login form and nothing else. Search engines are asked not to index the page (`robots.txt`
and a `noindex` meta tag).

The deck source is private. Its build script generates every file here, so do not edit them by hand.
